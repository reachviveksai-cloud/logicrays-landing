04 · The gap

Magento wasn't built for AI shoppers.

A great Magento store can still be invisible to an agent. The signals a machine needs are exactly the ones that are easy to leave incomplete.

  • Structured data an agent can parse, not just pretty pages
  • Clean product feeds with price and availability that agree
  • Verified identity the agent can trust before it buys
  • Quotable return and shipping terms, not a policy PDF
  • A checkout an agent can actually drive

It looks fine to a human. It fails silently for a machine.

05 · The stakes

The store an agent can't read doesn't get a “no.” It gets skipped.

No error page. No bounce-rate spike. No warning. The agent simply recommends a competitor it can read, and every month you stay unready you forfeit a slice of a channel that is compounding fast.

06 · What “ready” means

Getting AI-ready isn't one switch. It's five layers.

AccessCan the agent reach your store at all?Layer 1
ComprehensionCan it understand what you sell?Layer 2
Identity & TrustCan it trust you enough to transact?Layer 3
TransactabilityCan it actually complete the purchase?Layer 4
ReliabilityDoes it stay true, every time?Layer 5

Fail one layer and everything above it stops mattering. And the bar keeps moving as new standards (ACP, AP2, MCP) ship. Readiness is not a one-time fix.

Appendix · The standards

Built to the standards agents use.

  • ACP · Agentic Commerce Protocol (OpenAI + Stripe) governs how an agent completes a purchase. Powers checkout in ChatGPT.
  • AP2 · Agent Payments Protocol (Google + 60 payment networks) governs trusted, authorised agent payments.
  • MCP · Model Context Protocol (Anthropic) governs how an agent reaches and reads your store's data.

Goofre™ measures your store against these standards, so your readiness is held to a public bar, not our opinion.
